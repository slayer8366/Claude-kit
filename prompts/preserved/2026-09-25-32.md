**session_agents.py** is read-only and Python 3.8-compatible, with the standard library only. The module docstring states the rule first.
- **Usage:** `python3 session_agents.py <session.jsonl>`. It finds `<dir>/<sessionId>/subagents/` from the log's path.
- **Parsing:**
  - It parses each line as JSON. A line that doesn't parse is reported as "line N: not JSON (truncated or partial)" and skipped, never a crash. Only the final line is expected to be partial; report any other bad line the same way.
  - It works on both key orders.

  - timestamp, tool_use id, subagent_type, description, foreground or background, and line number (as a hint only)

- **Summary line:** counts per outcome.
- **Exit code:** 0 when the log was read, even if some lines were bad; 2 on a usage error or a missing file.
