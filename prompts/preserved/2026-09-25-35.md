Usage:
`python3 launch_session.py --cwd <checkout> --prompt-file <file> --out <stream file> [--expect-commit <sha>] [--timeout 600] [--max-budget-usd <n>] [--model <m>] [--claude <path>] [--grace 15]`

It runs these steps in order:
1. **Pre-check the checkout.**
   - `<cwd>` is a git checkout with no tracked changes.
   - Its HEAD equals `--expect-commit`. The default is `origin/<first protected branch from <cwd>/.claude/kit.json>` as last fetched; the launcher does not fetch.
   - On a mismatch, exit with the "wrong session" code and a reason, and start nothing.
2. **Hooks check.**
   - Run `<claude> --init-only` in `<cwd>`, under the same timeout and kill rules as step 3, and capture its output.
   - If session_check reported anything (its "Claude-kit session_check:" text, in whatever form `--init-only` surfaces it), exit "wrong session" and quote the text.
   - Premise P7 below must hold first.
3. **Launch.**
   - Generate a UUID and run `<claude> -p --session-id <uuid> --output-format stream-json --verbose --permission-prompts none`, plus `--max-budget-usd` and `--model` when given.
   - The prompt goes on stdin, cwd is `<cwd>`, and the process starts in its own session/process group (`start_new_session=True`).
   - Stream stdout to `--out`, line by line and verbatim. Stderr goes to `<out>.stderr`.
4. **Identity.**
   - Read the stream as it arrives. The first `system`/`init` message must show `session_id` equal to the UUID and `cwd` equal to the real path of `<cwd>`.
   - A mismatch, or no init message by the limit, means: kill (step 5), exit "wrong session" or "failed to start", with the reason.
5. **Time limit.**
   - Wall-clock `--timeout` seconds, default 600, counted from launch.
   - At the limit: SIGTERM to the process group, wait `--grace` seconds (default 15), then SIGKILL the group.
   - Then confirm that no process of the group is left (`os.killpg(pgid, 0)` raising ProcessLookupError, or /proc). If one is, say so and exit with the timed-out code anyway.
